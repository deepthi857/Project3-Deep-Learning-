# Project3-Deep-Learning-
Team Members: S Deepthi Reddy, Meka Shashank, G Sai Maitra ; Context-aware two-tower deep learning recommendation engine for fashion e-commerce, built on the H&amp;M dataset. Uses PySpark for data processing, TensorFlow Recommenders for the model, Redis for caching and FastAPI for real-time recommendations.
